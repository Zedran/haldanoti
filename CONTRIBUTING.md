# Contributing Guidelines

Thank you kindly for considering contributions.

## Repository submissions

Please do not submit content generated or "co-authored" to any extent by AI tools, or machine translations made by any means.

If you would like to translate the game, feel free to open a pull request. Refer to the [translation guide](docs/dev/translations.md) before contributing.

No other submissions to the repository are currently accepted.
