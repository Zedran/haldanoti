# Security Policy

## Reporting security issues

To report a security issue, please use the [Report a vulnerability](https://github.com/Zedran/haldanoti/security/advisories/new) option, found in the repository's **Security** tab.

## Supported versions

Security updates are applied to the most recent version of the game.

## Methodology

You are welcome to use any reasonable methodology to create reports, including AI-assisted processes. It is important, however, that you understand the report and are able to reproduce issues yourself on the most recent release.

## Recognition

I do not offer monetary rewards for security reports, but I will credit the reporter of a valid, original issue, unless they ask to remain anonymous.
